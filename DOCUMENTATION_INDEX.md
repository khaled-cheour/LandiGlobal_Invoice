Tables SQL Server (7 au total):

1. InvoiceHistories (Master)
   ├─ Colonnes principales:
   │  ├─ Id (PK), InvoiceNumber (Unique)
   │  ├─ CustomerName, Email, Phone
   │  ├─ TotalAmount, Currency, Status
   │  ├─ CreatedAt, UpdatedAt
   │  └─ IsValidated, IsEnriched, ErrorMessage
   ├─ Indexes: InvoiceNumber, CustomerName, CreatedAt, Status
   └─ Relations: 1 → Many (Products)

2. InvoiceHistoryProducts (Details)
   ├─ Colonnes:
   │  ├─ Id, InvoiceHistoryId (FK), ProductNumber
   │  ├─ Quantity, UnitPrice, TotalAmount
   │  └─ HSCode, MemoryPlan, etc.
   └─ Relation: Many → 1 (InvoiceHistory)

3. AspNetUsers (Identity)
   ├─ Colonnes: Id, Email, UserName, FirstName, LastName
   ├─ Phone, Department, CreatedAt, LastLogin, IsActive
   └─ Password (hashed)

4. AspNetRoles (Identity)
   ├─ Roles seeded on startup:
   │  ├─ Admin (Full access)
   │  ├─ Manager (Can manage users)
   │  ├─ User (View/Create invoices)
   │  └─ Auditor (View logs)
   └─ Permissions via [Authorize(Roles="Admin")]

5. AspNetUserRoles (Identity mapping)
   └─ Links users to roles (Many-to-Many)

6. AuditLogs
   ├─ Colonnes: Id, UserId (FK), Action, TableName
   ├─ OldValues, NewValues (JSON)
   ├─ Timestamp, IpAddress
   └─ Usage: Tracer qui a modifié quoi quand

7. Dashboards
   ├─ Colonnes: Id, UserId (FK), Statistics (JSON)
   └─ Usage: Cacher dashboards personnalisés
