## 🔍 Comment Utiliser Ce Catalogue

### 1. **Rechercher un Produit**
- Utilisez Ctrl+F (Windows) ou Cmd+F (Mac)
- Entrez le numéro ou la famille
- Exemple: `53004` → M20SE standard

### 2. **Trouver des Détails**
- Vérifiez la Platform (Android/Windows/Warranty)
- Consultez MainDisplay et SecondDisplay
- Vérifiez Memory et connectivité (4G, GMS)

### 3. **Comparer les Variantes**
- M20SE vs M20: M20 a imprimante intégrée
- 3GB+32GB vs 4GB+64GB: Plus de mémoire = plus cher
- Avec Scanner: LANDI vs Honeywell vs sans

### 4. **Intégrer dans vos Factures**
- Copier le Product Number exactement
- Le système validera et enrichira automatiquement
- La Description s'affichera dans le PDF
